# Fietland – Tag 1 🏝️

Ein vertikales Kurzvideo (1080×1920, 30 fps, ca. 48 s) für TikTok, Reels und Shorts. Es nutzt das Serien-Format
„**Tag 1: Ich habe … eröffnet. 1 Follower = 1 Kunde. Ihr entscheidet.**“, aber mit eigener Idee, eigenen Figuren
und eigenem Look.

**Fertiges Video:** [`out/fietland_tag1.mp4`](out/fietland_tag1.mp4) · **Cover:** [`out/cover.png`](out/cover.png)

## Die Idee

**Fiete** (gelber Friesennerz, Elbsegler-Mütze, rote Haare) gründet an Tag 1 sein eigenes Land: **Fietland**, eine
Sandbank in der Nordsee. **Jeder Follower wird ein Einwohner.** Die Community entscheidet per Kommentar und Like,
was mit der Staatskasse passiert. Fiete baut das Land so Tag für Tag mit seinen Followern auf.

| Figur | Rolle | Running Gag |
|---|---|---|
| **Fiete** | Präsident, Erzähler | Optimist mit 12 m² Staatsgebiet (bei Flut: 4 m²) |
| **Jürgen** | Möwe, Finanzminister (mit Krawatte) | Gehalt: 1 Fischbrötchen am Tag. Klaut alles, was glänzt. |

## Warum das Format funktioniert und wie das Video es umsetzt

| Mechanik | Umsetzung im Video |
|---|---|
| Hook in Sekunde 1 | großes „TAG 1“, danach „Ich habe mein eigenes Land gegründet“ |
| Teilnahme-Versprechen | „Jeder neue Follower wird ein Einwohner“ mit Profil-Karte und „+1 Einwohner“ |
| Underdog-Start, der Mitleid und Lacher holt | Sandbank, Plastikpalme, „Einwohner: null“, leere Fähre, nur eine Gummiente |
| Witziger Sidekick | Jürgen, die Möwe mit Krawatte, klaut Fietes Mütze |
| Großer Traum | Globus: „Heute eine Sandbank, irgendwann auf jeder Weltkarte“ |
| Follow-Aufforderung mit Belohnung | „Also folg jetzt“ mit animiertem Folgen-Button |
| Kommentar-Anreiz mit Zeitdruck | Gründer-Reisepass Nr. 001, nur heute, mit Countdown |
| Status für frühe Fans | „Morgen stehst du ganz oben auf der Einwohnerliste“ |
| Abstimmung, die Kommentare treibt | A: Flagge · B: Strandkorb für Jürgen · C: Was anderes |
| Schnitt-Tempo | etwa jede Sekunde ein neuer Schnitt, Untertitel Wort-für-Wort mit farbigen Schlüsselwörtern |

## Posting-Text (zum Kopieren)

```
Tag 1: Ich habe mein eigenes Land gegründet 🏝️ Jeder Follower = 1 Einwohner. Flagge, Strandkorb für Jürgen oder was ganz anderes? Ihr entscheidet 👇 #fietland #tag1 #community #nordsee #fyp
```

Profil-Bio: `Ich bau ein eigenes Land – mit euch 🏝️ 1 Follower = 1 Einwohner. Ihr entscheidet 🗳️`

Tipps:
- Bitte die ersten Kommentare selbst anpinnen („Gründer-Reisepass Nr. 001 geht an …“). Das belohnt Kommentierende sichtbar.
- Antworte in Tag 2 per Video-Antwort auf den meistgelikten Kommentar. Das hält die Serie in Gang.
- Poste regelmäßig zur gleichen Uhrzeit. Ein Format mit „Tag X“ lebt von der Erwartung an die nächste Folge.

## Serien-Ideen für die nächsten Tage

- **Tag 2:** Abstimmungsergebnis umsetzen (z. B. Flagge hissen, Entwurf aus den Kommentaren). Einwohnerzahl zeigen, die ersten Namen auf der Liste.
- **Tag 3:** Nationalhymne (Community schreibt die Zeilen), Jürgen klaut das Notenblatt.
- **Tag 4:** Erster Staatsbesuch: die Gummiente. Fähre MS Moin legt wieder an, diesmal mit Passagieren.
- **Tag 5:** Grenzstreit mit einer Krabbe. Staatskasse für eine Sandburg-Mauer?
- **Meilensteine:** 100 / 1.000 / 10.000 Einwohner ⇒ die Insel wächst sichtbar (Steg, Leuchtturm, zweite Palme – diesmal echt).

## Technik und selbst neu rendern

Alles ist Code. Für Text, Timing oder Farben musst du nur die Dateien anpassen und neu rendern.

| Datei | Inhalt |
|---|---|
| `script.json` | Sprechertext, Untertitel (`^` gelb, `!` rot, `~` blau hervorgehoben), Soundeffekt-Cues |
| `build_timeline.py` | Sprachausgabe pro Satz (Piper TTS, Stimme „Thorsten“), daraus Timing und Mundbewegung |
| `index.html`, `style.css`, `scene.js` | die komplette Animation (eigenes SVG-Artwork). `renderAt(t)` zeichnet jeden Frame deterministisch. |
| `render.cjs` | rendert Frames mit Chromium/Playwright und erzeugt das H.264-Video |
| `audio.py` | synthetische Musik und Soundeffekte (lizenzfrei), Mix mit Ducking, Lautheit −14 LUFS |

```bash
npm install                                    # Schriften (Nunito, Fredoka)
pip install piper-tts numpy                    # TTS
# Stimme: vits-piper-de_DE-thorsten-high (z. B. aus den sherpa-onnx tts-models Releases)
python3 build_timeline.py <pfad>/de_DE-thorsten-high.onnx
node render.cjs                                # -> build/video_noaudio.mp4
python3 audio.py                               # -> build/mix.wav
ffmpeg -i build/video_noaudio.mp4 -i build/mix.wav -c:v copy -c:a aac -b:a 192k -shortest -movflags +faststart out/fietland_tag1.mp4
```

Zum Prüfen einzelner Bilder: `node render.cjs --stills 1.5,10.2` oder `node render.cjs --sheet` (ein Bild pro Schnitt).
Emojis kommen aus der Systemschrift „Noto Color Emoji“ (`fonts-noto-color-emoji`).

**Eigene Stimme statt TTS:** Nimm das Skript oben selbst auf (ca. 48 s) und ersetze `build/vo.wav`. Die Schnitte sind
auf die TTS-Timings abgestimmt. Bei abweichendem Tempo lieber pro Satz aufnehmen und die Zeiten in `build/timeline.json` anpassen.
